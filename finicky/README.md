Always open the right browser

```sh
brew install --cask finicky
ln -sf "$PWD/finicky/finicky.js" ~/.finicky.js
```

The configuration sends every URL opened from Discord (`com.hnc.Discord`) and all `pastemega.com` URLs to Brave Browser. Restart Finicky after changing the configuration.

Ref: https://github.com/johnste/finicky
